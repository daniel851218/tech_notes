# Atkinson Hyperlegible Next

Variable WOFF2 fonts, weights 200–800, upright and italic, with Latin and Latin Extended subsets. The browser loads only the subsets and styles needed by the page.

- Typeface: [Braille Institute](https://www.brailleinstitute.org/freefont/)
- Webfont files: [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Atkinson+Hyperlegible+Next:ital,wght@0,200..800;1,200..800&display=swap), font asset version v7
- License: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegiblenext), bundled as `OFL.txt`

Files are served locally. Font-face declarations and Unicode ranges are in `assets/css/fonts.css`.
