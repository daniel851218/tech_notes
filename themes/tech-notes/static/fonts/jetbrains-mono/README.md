# JetBrains Mono

Unmodified WOFF2 webfonts for regular, italic, bold, and bold italic code text. Programming ligatures are disabled through CSS for both code blocks and inline code.

- Source: [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d/fonts/webfonts)
- Source commit: `19371302b95d218af43299bce79ddbddd0bc364d`
- License: SIL Open Font License 1.1, bundled as `OFL.txt`

Files are served locally. Font-face declarations are in `assets/css/fonts.css`.
