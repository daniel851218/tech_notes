# STIX Two Math

Unmodified WOFF2 math font used by the browser's native MathML renderer for both inline and display equations.

- Source: [STIX Two release v2.13b171](https://github.com/stipub/stixfonts/tree/v2.13b171/fonts/static_ttf_woff2)
- Font: `STIXTwoMath-Regular.woff2`
- License: SIL Open Font License 1.1, bundled as `OFL.txt`

The complete math font is bundled to preserve its mathematical glyph coverage and OpenType MATH layout data. The file is served locally and loaded only on pages that use it. Font-face declarations are in `assets/css/fonts.css`.
